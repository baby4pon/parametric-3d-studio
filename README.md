# パラメトリック3Dモデル生成スタジオ (Parametric 3D Studio)

寸法を入力するだけで3Dプリンター用データ（`.3mf` / `.stl`）をブラウザ上で即座に生成できる、ローカル完結型のパラメトリックCADスタジオです。

## 主な機能
- **6種類の厳選3Dジェネレーター**:
  - 仕切り付きボックス Pro（2Dセル結合エディタ・外壁模様・スタッキング・蓋対応）
  - Gridfinity 収納ビン（42mm規格・ラベル棚・スクープ・底面マグネット穴）
  - Gridfinity ベースプレート（42mmグリッド・外周余白スペーサー）
  - openGrid 壁面収納ボード（角穴・丸穴・六角穴・裏面スペーサー脚）
  - 多目的フック・ツールホルダー（ネジ穴・両面テープ・デスククランプ）
  - ケーブル＆ガジェットスタンド（傾斜スロット・小物トレイ・ケーブルスリット）
- **3D寸法線オーバーレイ**: 外寸（W/D/H）およびセル内寸を3D空間にリアルタイム表示
- **実寸iPhone比較モデル**: 実物大（147.6×71.6×7.8mm）モデルを表示し、横置き/縦置きを切り替え可能
- **3MF / STL出力 ＆ 3MF再編集**: `.3mf` 内に設定JSONを保存し、ドラッグ＆ドロップで当時の状態を完全復元
- **URLパラメータ同期 ＆ AI連携（`llms.txt` / 自然言語パーサー）**

## 開発・起動方法
```bash
npm install
npm run dev
```
