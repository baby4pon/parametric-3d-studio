# 実装計画: パラメトリック3Dモデル生成スタジオ（yoshida3d.com風ローカルWebアプリ）

## 1. 概要とゴール
`https://yoshida3d.com/` のコンセプト（CAD不要・寸法を入れるだけで3Dプリンター用データ `.3mf` / `.stl` をブラウザ上で即座に生成）をローカル環境で完結・拡張して動作する Web アプリケーション **`parametric-3d-studio`** を構築する。

## 2. 実装機能
1. **厳選6種の3Dジェネレーター**
   - `divided-box-pro`（仕切り付きボックス Pro：外寸・列/行・2Dセル結合・壁模様・スタッキング・蓋）
   - `gridfinity-bin`（Gridfinity 収納ビン：42mm規格ベース段差・仕切り・リップ・ラベル棚・スクープ・磁石穴）
   - `gridfinity-baseplate`（Gridfinity ベースプレート：42mmグリッド枠・軽量/底板切替・外周スペーサー）
   - `opengrid-board`（openGrid 壁面収納ボード：角穴/丸穴/六角穴・ビス穴・裏面スペーサー脚）
   - `wall-hook-holder`（多目的フック・ツールホルダー：J/L字・ビス穴/両面テープ/デスククランプ）
   - `desk-organizer-tray`（ケーブル＆ガジェットスタンド：傾斜スロット・小物トレイ・ケーブルスリット）
2. **CADビューポート＆比較ギミック**
   - 256×256mm ビルドプレート表示・カメラプリセット（上 / 正面 / 右 / 下 / 全体）
   - 3D寸法線オーバーレイ（外寸 W/D/H および内寸のリアルタイム描画）
   - 実寸 iPhone 16（147.6×71.6×7.8mm）比較モデル表示と横置き/縦置き切替
3. **エクスポート / インポート / AI連携**
   - Z-up ミリメートル単位のバイナリ `.stl` 生成
   - `.3mf` 生成（`3D/3dmodel.model` + `Metadata/yoshida3d_project.json` + サムネイルPNG）とドラッグ＆ドロップによる設定復元
   - URLクエリ同期、`public/llms.txt` 仕様テキスト提供、日本語自然言語テキストからのパラメータ自動設定パーサー
4. **インダストリアルUI**
   - セーフティイエロー (`#ffb000`) × ブラック斜めハザードストライプ、`border-radius: 0`、`1.5px solid` ボーダー、ダーク/ライトテーマ切替

## 3. ディレクトリ構成
- `public/llms.txt`: AI自動生成向け仕様書
- `src/types.ts`: パラメータ・ツール定義・状態型定義
- `src/tools/*`: 6種のジオメトリ生成ロジックおよび共通押し出しヘルパー
- `src/viewport/*`: Three.js シーン管理・3D寸法線・iPhoneモデル
- `src/io/*`: STL/3MFコーデック・URL/AIパーサー
- `src/ui/*`: ホーム画面・フルスクリーン3Dエディタ画面
- `src/main.ts`, `src/style.css`: ルーティング・統合・デザインシステム

## 4. 検証方針
- `npm run build`（`tsc && vite build`）による静的型検査・ビルド確認
- Vite開発サーバーを起動し、実ブラウザ上でホーム画面・各ツール・3D表示・寸法線・iPhoneモデル・パラメータ編集・2Dセル結合・ダウンロードの動作を確認
