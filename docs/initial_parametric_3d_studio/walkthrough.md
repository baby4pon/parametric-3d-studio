# 修正・実装内容の確認 (Walkthrough)

## 1. 実装概要
`https://yoshida3d.com/` のコンセプトである「CAD不要・寸法を入れるだけでブラウザ上で3Dプリンター用データ（.3mf / .stl）を即座に作れる」Webアプリケーション **`parametric-3d-studio`** をローカル完結構成（Vite + TypeScript + Three.js + JSZip）で構築しました。

## 2. 主な実装ファイルと機能

### 2.1 厳選6種のパラメトリック3Dジェネレーター (`src/tools/`)
1. **`dividedBoxPro.ts`（仕切り付きボックス Pro）**:
   - 外寸 (W/D/H)、列・行、壁厚・底厚・仕切り厚、角丸半径。
   - **2D仕切りセル結合エディタ**対応（隣接する仕切り壁を個別に消して大部屋化）。
   - スタッキング段差、外壁テクスチャ（フラット / 横リブ / 縦ローレット / ブロックレリーフ）、専用蓋出力（本体のみ / 蓋のみ / 本体＋蓋セット）。
2. **`gridfinityBin.ts`（Gridfinity 収納ビン）**:
   - 42mmピッチ・7mm高さユニット規格準拠の底面テーパー足、内部仕切り、スタッキングリップ、ラベル棚、指入れスクープ、φ6.5mm底面マグネット穴。
3. **`gridfinityBase.ts`（Gridfinity ベースプレート）**:
   - 42mmグリッド受け枠、軽量フレーム型／底板付き高剛性型、引き出し内寸合わせ用の外周余白スペーサー（padX / padY）。
4. **`opengridBoard.ts`（openGrid 壁面収納ボード）**:
   - ピッチ選択（25/28/30mm）、穴形状（openGrid角穴 / ペグ丸穴 / ハニカム六角穴）、四隅ビス穴、裏面スペーサー脚。
5. **`wallHookHolder.ts`（多目的フック・ツールホルダー）**:
   - J/L字フック、固定方式切替（M4ビス穴フランジ / フラット両面テープ / デスク天板クランプ）。
6. **`deskOrganizerTray.ts`（ガジェットスタンド＆トレイ）**:
   - 傾斜スロット、手前小物トレイ、背面中央の充電ケーブルスリット。

### 2.2 3Dビューポート・ギミック (`src/viewport/`)
- **`sceneManager.ts`**: 256×256mmビルドプレート、CAD輪郭線 (`EdgesGeometry`)、カメラ視点プリセット（全体 / 上 / 正面 / 右 / 下）、4色フィラメントカラー切替。
- **`dimensionOverlay.ts`**: 外寸 (W / D / H) およびセル内寸を矢印付き寸法線・引き出し線・ラベルでリアルタイム描画。
- **`iphoneModel.ts`**: 実寸 iPhone 16（147.6×71.6×7.8mm）比較モデルを表示し、モデル直接クリックまたはボタンで横置き/縦置きを切り替え可能。

### 2.3 ファイル入出力・AI連携 (`src/io/`, `public/llms.txt`)
- **`stlExporter.ts`**: Three.js (Y-up) からスライサー標準の Z-up ミリメートル単位のバイナリ `.stl` を生成。
- **`threemfCodec.ts`**: `.3mf`（`3D/3dmodel.model` + `Metadata/yoshida3d_project.json` + サムネイルPNG）の出力、および `.3mf` ドラッグ＆ドロップ読み込みによる設定完全復元（外部汎用 `.3mf` 時はバウンディングボックス抽出フォールバック）。
- **`urlAndAiParser.ts`**: URLクエリパラメータの双方向同期、日本語自然言語入力からのパラメータ自動生成パーサー、`public/llms.txt` 提供。

### 2.4 UIデザイン (`src/style.css`, `src/ui/`)
- セーフティイエロー (`#ffb000`) × ブラックの斜めハザードストライプ、`border-radius: 0`、`1.5px solid` ボーダーによるインダストリアル・ワークショップUI（ダーク/ライトテーマ切替対応）。
- 数値入力の長押し連続増減、Undo/Redo (`Ctrl+Z` / `Ctrl+Y`)、スライサー推奨設定モーダル。
